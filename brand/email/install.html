On Gmail's dark theme. Gmail runs its own colour transform over message content and lifts dark text rather than letting it disappear, so this does not need a second version. The wordmark is set in the darker brass because white is the default and what almost every recipient sees — the lighter brass measures 2.85:1 on white and the thin script strokes wash out. If a dark ground is ever the target, wordmark-signature-dark.png in this folder is the same mark in the lighter brass.

Put it into Gmail

  1. Press Copy signature below.
  2. In Gmail, open Settings → See all settings → General and scroll to Signature.
  3. Create a signature, click into the editing box, and paste with Ctrl+V (⌘V on a Mac).
  4. Set it as the default for New emails and for On reply/forward, then Save changes at the bottom.

If the button does not work in your browser, select the signature in the white box above with the mouse, from just above the wordmark to the end of the last line, and copy it normally. Pasting a selection carries the formatting.

Worth knowing

  1. The wordmark is served from mareleborgne.com. It has to stay there, or the image breaks in every signature already sent.
  2. Many people read mail with images blocked. That is why the name and the studio appear as real text under the wordmark rather than inside it.
  3. For the plain-text signature some clients ask for, use signature.txt in this folder.
