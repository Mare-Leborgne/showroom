Brand assets

Every mark, and the sources to rebuild them. Usage, colour rules and the email signature are in README.md.

The logo

The signature sitting on water. The studio is called mare, the hero already floats the name on a moving sea, and a signature conventionally sits on a ruled line — so one wave is waterline and signature rule at once. Two lines, because that is already the mark.

On a ground of its own

For the times a transparent PNG would be dropped onto the wrong colour by somebody not thinking about it. Brass on navy is the site’s own pairing.

The wordmark

On its own, transparent. Letters converted to outlines, so it renders the same on a machine that has never heard of Pinyon Script.

The mark

The hero’s two contour lines. Stands in for the name where there is no room for it.

Other lockups

The mark set beside the name rather than under it, at fixed proportions so the spacing is not re-invented each time.

Social

Avatars are square and everything sits inside the inscribed circle, because every platform crops them round.

The email signature

Gmail loads no webfonts and strips stylesheets, so the script is an image and every rule is inline. Open the installer →

Colours

Rebuilding

The font makes the SVGs, the SVGs make the PNGs. Nothing is drawn twice, so the set cannot drift.

cd brand/_src && npm install opentype.js puppeteer-core && node rebuild-brand.js
